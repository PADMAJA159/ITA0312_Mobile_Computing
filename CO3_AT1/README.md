# Mobile App UI Projects — GitHub Starter Pack

This ZIP contains four responsive web UI prototypes:
1. MindWell — mental wellbeing and self-care
2. CareerPath — intelligent job assistant
3. ParkBuddy — parking availability and booking
4. FitLife — fitness, diet planning, videos, and subscriptions

Each folder includes `index.html`, `style.css`, `script.js`, and `README.md`.

## Upload to GitHub
1. Extract the ZIP.
2. Create a new GitHub repository.
3. Upload the folders or the extracted contents.
4. Preview by opening any `index.html` file in a browser. To publish, enable GitHub Pages in Settings → Pages.

Important: forms and buttons provide demo interactions only. Real login/register, resume upload storage, live parking availability and bookings, video hosting, subscriptions, and payments require backend services and secure integrations.
